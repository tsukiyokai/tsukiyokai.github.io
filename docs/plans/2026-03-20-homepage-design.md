# Personal Blog Design

## Overview

技术博客 + 作品展示的个人站点。视觉走danluu.com路线：接近零CSS，系统默认字体，浏览器默认配色，内容即设计。

## Decisions

| Dimension | Decision                                          |
|-----------|---------------------------------------------------|
| Purpose   | 技术博客(技术+生活) + 作品展示                    |
| SSG       | Zola (Rust)                                       |
| Deploy    | GitHub Pages + GitHub Actions                     |
| Visual    | danluu-style, near-zero CSS, system fonts, no color customization |
| Comments  | None, social/contact links at page footer         |
| Content   | Markdown, tags taxonomy for categorization        |

## Pages

Homepage (`/`):
- Name + one-line intro
- Nav links: Blog / Projects
- Latest 5 posts (title + date)
- Social links (GitHub, etc.)

Blog list (`/blog/`):
- Reverse chronological, title + date + tags
- Tag pages auto-generated by Zola

Blog post (`/blog/<slug>/`):
- Title, date, tags, body
- Code syntax highlighting (Zola built-in)
- Social/contact links at bottom

Project list (`/projects/`):
- Project cards: name, one-liner, tech stack tags, link

Project detail (`/projects/<slug>/`):
- Description, screenshots, repo link

## Visual Style

Reference: danluu.com

- Colors: browser defaults (black text, white bg, blue links)
- Fonts: system defaults, no external fonts loaded
- Layout: single column, no max-width constraint, browser default margins
- Nav: plain text links, no buttons or icons
- Separators: blank lines, no `<hr>` or decorative rules
- CSS: near-zero, only essential overrides (~10-20 lines)
  - `img { max-width: 100%; height: auto; }`
  - `pre { max-width: 100%; white-space: pre-wrap; }`
- No external resources: no fonts, no icon libs, no JS

## Technical Details

Zola config (`config.toml`):
- `base_url` = GitHub Pages URL
- `taxonomies` = `[{name = "tags"}]`
- `highlight_code = true`, plain theme
- `generate_feeds = false`
- `minify_html = false`

GitHub Actions:
- Trigger on push to main
- Install Zola -> `zola build` -> deploy to gh-pages branch

Post frontmatter format:
```toml
+++
title = "Post title"
date = 2026-03-20
[taxonomies]
tags = ["tech"]
+++
```
